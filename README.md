# Câmara Municipal de Ipiranga do Piauí

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um trabalho acadêmico da disciplina de Programação para a Web 1, tendo como tema uma **Câmara de Vereadores**.

A proposta consiste no desenvolvimento de uma interface web institucional para representar, de forma simples e organizada, um portal da **Câmara Municipal de Ipiranga do Piauí – PI**.

O projeto foi desenvolvido utilizando **HTML e CSS**, com foco na organização das informações, acessibilidade, responsividade e facilidade de navegação.

A página apresenta informações institucionais, vereadores, sessões, projetos e leis, transparência e um espaço de contato com a Câmara.

> **Observação:** o projeto possui caráter acadêmico e apresenta uma interface/protótipo para fins de desenvolvimento e estudo de programação web.

---

## 🎯 Objetivo

O principal objetivo do projeto é desenvolver uma página web institucional que permita ao usuário encontrar de forma simples informações relacionadas ao Poder Legislativo Municipal.

A interface foi planejada para:

- apresentar a Câmara Municipal;
- facilitar a navegação entre as diferentes áreas da página;
- apresentar os vereadores em uma seção própria;
- disponibilizar uma área para sessões;
- organizar links para projetos, leis e documentos;
- disponibilizar uma área de transparência;
- oferecer um formulário de contato;
- utilizar recursos de acessibilidade;
- adaptar a interface para diferentes tamanhos de tela.

---

## 💻 Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias básicas de desenvolvimento web.

### HTML

Utilizado para estruturar todo o conteúdo da página.

Foram utilizados elementos semânticos como:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<aside>`
- `<form>`
- `<footer>`
- `<table>`

A utilização desses elementos permite organizar melhor o conteúdo e contribui para a acessibilidade da página.

### CSS

Utilizado para:

- estilização da página;
- definição das cores;
- organização dos elementos;
- criação dos cards;
- criação do layout em Grid;
- responsividade;
- estados de foco;
- espaçamento;
- tipografia;
- bordas e sombras;
- adaptação para dispositivos móveis.
